# Sheet helper preview implementation and handoff

## Goal and approved scope

Build a Google Sheets season/liga/team helper before the season-aware website.
The user clarified that the preview belongs in TEST-prefixed tabs inside the
existing results workbook, not a separate spreadsheet file. Preserve the live
CURRENT source, refresh code, manifest, trigger registrations and workbook settings.
No site changes, historical imports, score publication or deployment are authorized.
Unrelated untracked `.agents/` and `.codex/` files remain untouched.

## Implementation

1. Apps Script OAuth, Cloud API enablement and account API access were completed.
2. Backend, 300px sidebar, safe installers and tests are in `scripts/sheet-helper/`.
3. The additive installer backed up original source and hashed original cells. It
   added `TEST — Helper`, `_TEST_Seasons`, `_TEST_Ligas` and three helper script files.
   At installation read-back, all 16 original tabs and two original script files
   matched their pre-installation snapshots.
4. The user encountered Google 401 during the bound script's first-run consent.
   Private-window retry had no response. Google documentation confirms new services
   can require the original trigger creator to reauthorize existing triggers.
5. The added script files were therefore rolled back, with an exact read-back of
   original Code and manifest. TEST tabs were retained with a paused notice. Local
   helper source remains. Later CURRENT cell changes were observed; they were not
   reverted. A subsequent reinstall must review the changed baseline first.

## Tested capabilities

Draft season creation; copying ligas/teams without fixtures or scores; liga/team
editing; scheduled fixtures with UUIDs; direct score entry validation; test-only
current-season selection. No standings/ranking engine, historical import,
automatic fixture generation or production sync is included.

## Verification and boundaries

- Node tests execute real Apps Script source against in-memory Google adapters.
- Python tests check additive installation, target safety, collision checks and
  script-only rollback. The global-declaration guard parses JS scopes and compiles
  combined source without executing it; indented collisions have regression tests.
- Playwright exercises actual HTML at 300px/short viewport with explicit Google RPC
  test doubles. This is not real Sheets end-to-end execution.
- Run npm test/lint/typecheck/knip/build and Python installer tests before commit.
  Whole-worktree Prettier includes four unrelated untracked `.agents/` skill files
  with pre-existing formatting issues; check task files and tracked files separately.
- Actual helper execution and a post-rollback live trigger cycle remain unverified.
- No main merge or push: branch pushes automatically deploy website previews.

## Resume gate

Have the original trigger creator available. Resolve Google first-run consent
before leaving added permissions on the live project. Inspect fresh workbook and
script state, reconcile the existing installation backup against later live edits,
and reinstall only after approval. Verify real sidebar season/liga/fixture flow,
then read back TEST data and confirm the existing refresh remains operational.
Do not invoke live dispatch or reinstall triggers as a preview test.
